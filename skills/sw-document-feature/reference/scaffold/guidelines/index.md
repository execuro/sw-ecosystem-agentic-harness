# Guidelines

{{PROJECT_NAME}} has no coding guidelines of its own yet. Architecture, code and QA guidelines are
inherited as-is from the Shopware platform guidelines, served by the ShopwareDevKnowledgeBase MCP
at `platform/guidelines/<version>/` (the Shopware major, e.g. `6.7` for Shopware {{SHOPWARE_VERSION}}): the base files `architecture-guidelines.md`,
`code-guidelines.md`, `qa-guidelines.md`, plus surface files (`be-`, `fe-`, `admin-`,
`storefront-…guidelines.md`).

[Documentation guidelines](documentation-guidelines.md) is the exception: it holds this wiki's own
documentation rules (page shape, frontmatter, status vocabulary) and has no platform counterpart,
so it is served as is, never merged.

## Recording a project rule

A rule is written here only to override, extend, waive, or add to a platform guideline — never to
restate it. It comes only from a person's statement or an accepted ADR, never invented.

The rule lives in `guidelines/<same file name as the platform file>.md` — no version folder: project
guidelines always apply to the Shopware version installed in this project — with a `merge:` key
naming which platform section it acts on and how. Coding agents and verifiers never read this
file directly — they call `read_doc guidelines/<version>/<file>.md` on the MCP, which returns the
effective file: the platform text with this project's sections merged in.
