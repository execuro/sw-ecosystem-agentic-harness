# Decision records

The decisions this project is built on — technical, process, and the business decisions that shaped
the architecture. A record lands here only once it is both accepted and actually built; until then
it stays a work-in-progress file under `specs/*-adr-*.md`.

Records follow Shopware's own ADR convention: `YYYY-MM-DD-title.md`, front matter
`title`/`date`/`area`/`tags`/`authors`/`status`, and the sections Context / Decision / Consequences.
This folder is the source of truth — later status changes (superseded, deprecated) are made here, by
people. Nothing in it is generated by tooling.
